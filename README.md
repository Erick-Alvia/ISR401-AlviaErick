# 📂 Repositorio de Ingeniería de Requerimientos

Repositorio centralizado para el almacenamiento, control de versiones y gestión de todas las actividades, proyectos prácticos, evaluaciones individuales y trabajos grupales de la asignatura de **Ingeniería de Requerimientos**.

---

## 📌 Estructura del Repositorio

El repositorio se encuentra organizado por módulos y tipos de entrega para facilitar la trazabilidad y el acceso a la documentación:

```text
.
├── .github/              <-- Plantillas de issues y flujos de trabajo
├── TrabajosGrupales/           <-- Trabajos, tareas y prácticas individuales
├── TrabajosIndividuales/               <-- Proyectos en equipo y entregas mayores
└── README.md             <-- Documentación principal del repositorio

```
### Orden de compilación
Ejecutar en la terminal del computador (se recomienda tener instalado MikTex):
dentro del terminal colocar el siguiente comando cd "Ruta donde se encuentra su archivo en el explorador"; 

ej: `cd "C:\Users\GAMEMAX\OneDrive\Documentos\00_Git\Prueba"`

luego colocar el siguiente comando: 

`pdflatex main.tex`

Volver a ejecutar permite actualizar correctamente la numeración, referencias internas y demás elementos generados por LaTeX:

`pdflatex main.tex`
