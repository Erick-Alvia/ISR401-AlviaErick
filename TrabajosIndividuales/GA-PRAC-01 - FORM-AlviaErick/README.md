## ⚙️ Compilación

Para generar el documento PDF a partir del código fuente, se recomienda utilizar **pdfLaTeX** mediante Overleaf, TeX Live o MiKTeX.

Ejecutar los siguientes comandos:

```bash
pdflatex main.tex
pdflatex main.tex
```

El proceso genera el archivo `main.pdf`, que contiene el documento compilado.
